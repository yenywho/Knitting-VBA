# Knitting-VBA
Excel macros and functions related to knitting that I talked about in my [blog](https://makingyenything.wordpress.com/).
## [Setup macros](/setup.bas)
Macros for setup things like adjust cell size to gauge, make major/minor grid lines, and set conditional formatting rules based on the first table in the active worksheet.
## [From clipboard](/fromclipboard.bas)
Macros that use an image of a colorwork chart in the clipboard to produce a colorwork chart in excel, either by changing cell color or filling cells with values based on the first table of the active sheet to be used with conditional formatting rules. 

A chart made with conditional formatting can then be manipulated with functions from [charttransform](/charttransform.bas) or converted to being a non-conditional formating chart and be used with the number macro to number color runs. Converting and number macros in [numbercolors](/numbercolors.bas).
## and various other stuff
Like macros to convert between knitting charts and instructions and vertical/horizontal highlighters that follow where you are on the sheet. And in [fun](/fun) I have some excel files that generate colorwork charts automatically.
